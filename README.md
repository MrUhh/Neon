# Neon - Virtual Robot Python Applied

Neon is a virtual robot simply build with Python. You can control neon on a 2D Grip map, generated and navigate around obstacles, manage energy by visit various generated charging station.

My name is Vincent, a first year student in Software Engineering at University of Ottawa. I'm building neon and committing my progress here to keep track and update it as my progress growth.

## Feature
**Grid Movement: Neon can move in fourth direction: North, East, South, West on a 10x10 map (-5,5)
**Obstacles generated and prevent: The map will generated random obstacles on the map and Neon can navigate that and prevent hitting those obstacles.
**Boundary Detected: Neon couldn't go beyond the boundary that I've assigned for it to be in there.
**Charging and manage it energy: Neon could alert when energy is low, and charge it up to full when reached on of the charging station on the map, prevent movement if there's not enough energy
**Map Preview: Program can print a 10x10 map with "O" represent Neon, "#" is obstacles, and "C" is charging station
**Status Preview: Program can print Neon status for us to keep track on Neon, preventing any energy failure and keep track for position of neon
